# File Server с внешним доступом

Этот проект представляет собой файловый сервер, который может быть доступен как локально, так и из интернета.

## Возможности

- Локальный доступ в сети
- Публичный доступ через интернет с использованием ngrok
- Поддержка загрузки и скачивания файлов
- Уведомления через Firebase Cloud Messaging (FCM)
- Поддержка WebSocket для real-time обновлений

## Установка

1. Убедитесь, что у вас установлен Node.js (рекомендуется версия 14+)
2. Клонируйте репозиторий
3. Установите зависимости:

```bash
cd file-server
npm install
```

## Варианты распространения APK

### 1. Локальный вариант (только в вашей сети WiFi)

1. Запустите сервер в локальном режиме:
```bash
npm start
```

2. Получите IP-адрес компьютера в локальной сети
3. Пользователи, подключенные к той же WiFi-сети, могут скачать APK, перейдя по адресу:
```
http://ВАШ_IP_АДРЕС:3000/download
```

### 2. Распространение через интернет (ngrok)

1. Зарегистрируйтесь на [ngrok](https://dashboard.ngrok.com/signup)
2. Получите ваш authtoken на странице [Your Authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)
3. Запустите сервер с публичным доступом:
```bash
npm run tunnel
```
4. При первом запуске вам будет предложено ввести ваш authtoken
5. После успешного запуска вы получите публичный URL (например, https://abcd1234.ngrok.io)
6. Пользователи могут скачать APK по адресу:
```
https://abcd1234.ngrok.io/download
```

## Запуск сервера

### Локальный запуск (доступен только в вашей сети)

```bash
# Используя npm
npm start

# Или используя bash-скрипт
./start-server.sh
```

### Запуск с публичным доступом через интернет

```bash
# Используя npm
npm run tunnel

# Или используя bash-скрипт с флагом
./start-server.sh --tunnel
```

После запуска с флагом `--tunnel` сервер будет доступен из интернета через URL, который будет выведен в консоль.

### Запуск через Docker

Для запуска в контейнере Docker:

```bash
# Сборка образа
docker build -t file-server .

# Запуск в локальном режиме
docker run -p 3000:3000 file-server

# Запуск с публичным доступом
docker run -p 3000:3000 -e USE_TUNNEL=true file-server
```

## Управление APK файлами

1. Загрузка APK:
   - Получите APK-файл вашего проекта из Android Studio (Build → Build Bundle(s) / APK(s) → Build APK(s))
   - Откройте панель управления по адресу http://localhost:3000/admin-app
   - Введите ключ администратора (по умолчанию: admin123)
   - Загрузите APK файл и укажите версию

2. Распространение APK:
   - После загрузки APK, поделитесь URL страницы скачивания с пользователями
   - Пользователи перейдут по ссылке, скачают и установят APK на свои устройства

## Настройка постоянного внешнего доступа

Если вам нужен постоянный доступ из интернета без использования ngrok (который имеет ограничения в бесплатной версии), вы можете:

1. Настроить порт-форвардинг на вашем маршрутизаторе, перенаправив порт 3000 на ваш компьютер
2. Использовать динамический DNS (DDNS) для создания постоянного домена, указывающего на ваш IP
3. Для защищенного соединения настроить SSL/TLS сертификат через Let's Encrypt

## Примечания по безопасности

1. При открытии доступа из интернета обязательно настройте авторизацию и аутентификацию пользователей
2. Рассмотрите возможность настройки HTTPS для защищенного соединения
3. Регулярно обновляйте зависимости для устранения потенциальных уязвимостей
