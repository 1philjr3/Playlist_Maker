# Руководство по настройке проброса портов для вашего сервера

## Проблема
Сервер запускается, но не доступен из интернета. Причина - не настроен проброс портов на вашем роутере.

## Что такое проброс портов?
Проброс портов (port forwarding) - это настройка на вашем роутере, которая указывает, какому устройству в вашей домашней сети отправлять запросы, приходящие извне на определенный порт.

## Шаги по настройке проброса портов

### 1. Определите локальный IP-адрес вашего компьютера

На Mac:
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

Ищите строку с IP-адресом в формате 192.168.xxx.xxx или 10.0.xxx.xxx.

### 2. Зайдите в панель управления роутером

- Обычно доступна по адресу: 192.168.0.1 или 192.168.1.1
- Введите логин и пароль администратора (может быть на наклейке на роутере)

### 3. Найдите раздел Port Forwarding

В зависимости от модели роутера, он может называться:
- "Проброс портов"
- "Port Forwarding"
- "Virtual Server"
- "Переадресация портов"
- "NAT" или "Перенаправление портов"

### 4. Добавьте новое правило проброса портов

Заполните следующие поля:
- **Название**: ProVita Server
- **Внешний порт**: 8080
- **Внутренний порт**: 8080
- **IP-адрес**: [локальный IP вашего компьютера, полученный в шаге 1]
- **Протокол**: TCP (или TCP/UDP)
- **Включено**: Да

### 5. Сохраните настройки и перезагрузите роутер при необходимости

### 6. Проверьте проброс портов

Запустите сервер и проверьте доступность:
```bash
cd file-server
chmod +x start-duckdns.sh
./start-duckdns.sh
```

### 7. Проверка через интернет

Попробуйте подключиться к серверу с любого устройства через мобильный интернет (не WiFi):
- http://provitaserver.duckdns.org:8080/download
- http://provitaserver.duckdns.org:8080/admin-app

## Возможные проблемы

### 1. Интернет-провайдер блокирует входящие соединения
Решение: Позвоните своему провайдеру и уточните, не блокируют ли они входящие подключения на порт 8080.

### 2. Двойной NAT
Если ваш роутер подключен к другому роутеру (или модему провайдера с функцией роутера), может потребоваться настройка проброса портов на обоих устройствах.

### 3. Брандмауэр компьютера
Убедитесь, что в настройках брандмауэра Mac разрешены входящие подключения на порт 8080.

### 4. Статический IP
Рекомендуется настроить статический IP-адрес для компьютера с сервером в локальной сети, чтобы он не менялся после перезагрузки.

### 5. Использование другого порта
Если порт 8080 не работает, попробуйте другие порты (например, 8081, 8082 и т.д.), изменив соответствующие настройки в скрипте start-duckdns.sh.
